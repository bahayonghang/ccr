# GPUI 桌面端

CCR 的原生桌面应用，在一个窗口里管理各编码工具的接入、定制和用量。本文件只收录这个界面里的用语。

## 页面结构

**平台目的地**（Platform destination）：
侧栏「平台」组里的一项，如 Claude Code、Codex。它只呈现这一个平台的内容。
_Avoid_: 平台页

**Claude Code 页面**：
Claude Code 这个平台目的地，包括它的全部平台 tab。
_Avoid_: Claude 首页（指工作台时）

**平台 tab**（Platform tab）：
平台目的地里的一个工具页。一个 tab 对应一个页面，选中哪个 tab，页面就只显示那一项。
_Avoid_: lens（代码里的名字）、子页

**工作台**（Workbench）：
平台目的地的第一个 tab，概括这个平台的当前状态和用量。
_Avoid_: 首页、主页、Home

**运行概览**（Overview）：
应用的默认首页，汇总所有平台。
_Avoid_: 仪表盘、Dashboard、首页

## 连接与身份

**执行环境**（Environment）：
桌面端读写配置、运行命令所作用的机器。本期为本地或一台 SSH 主机。

**当前执行环境**（Active environment）：
全局唯一、由用户在底部状态栏显式切换的执行环境。连接失败时保留所选主机，不回落本地。
_Avoid_: target、目标环境

**SSH 主机**（SSH host）：
一条保存的远程连接记录。选中主机不等于已连接；主机密钥信任与登录凭据分别处理。

**环境无关**：
只依赖 CCR 应用数据或网络服务、不读写平台机器配置的能力，例如签到管理、全局设置和操作记录存储。SSH 离线时仍可使用。

**配置方案**（Profile）：
一组有名字、可以切换的接入参数，如端点、凭据和模型。平台一次只用其中一个。
_Avoid_: 配置（单独使用时）、配置集、界面中文里的「Profiles」

**方案集合**：
当前平台保存的全部配置方案。对集合的导入、备份或恢复不等于将其中的方案应用到平台运行配置。
_Avoid_: 配置目录（指方案集合时，容易被理解为磁盘文件夹）

**解除当前方案**：
移除 CCR 为当前平台写入的接入覆盖，保留已保存的配置方案。它作用于当前正在使用的方案，不随列表选中项改变，也不保证自动恢复官方登录。
_Avoid_: Off、停用（指解除当前方案时）、退出登录

**平台账户**（Platform account，平台页简称「账户」）：
编码平台保存的一组登录凭据，可在平台页切换。
_Avoid_: 认证（指这个对象时）、Authentication

**签到账户**（Check-in account）：
本机签到库中归属一个签到提供商的账户。签到、余额和历史记录都按它的账户 ID 定位。

**签到提供商**（Check-in provider）：
签到账户访问的站点，可以从内置目录添加，也可以手动填写自定义站点。

**设置**（Settings）：
平台自己的设置文件，如 Claude Code 的 settings.json。
_Avoid_: 设置与来源

**配置来源**（Configuration sources）：
一项设置的生效值来自哪几层文件。
_Avoid_: 来源（单独使用时）

## 定制

**指令**（Instructions）：
告诉平台该怎么做的文本，包括指令文件、规则和输出样式。
_Avoid_: 资源、系统提示词

**指令文件**（Instruction files）：
平台启动时读取的说明文件，如 CLAUDE.md、AGENTS.md。
_Avoid_: System Prompts、系统提示词

**规则**（Rules）：
拆成多个文件、按主题组织的补充指令。

**输出样式**（Output styles）：
改变回复风格的预设指令。

**扩展**（Extensions）：
给平台增加能力的条目。Claude Code 的扩展是子代理、斜杠命令和插件，其他平台各有不同。
_Avoid_: 资源、代理与来源、代理与插件

**子代理**（Subagent）：
Claude Code 可以把任务委派出去的专用代理。
_Avoid_: Agents、代理配置（容易和 Agent 会话混淆）

**斜杠命令**（Slash command）：
在 Claude Code 会话里用 `/名称` 调用的命令。
_Avoid_: Commands、命令（侧栏的「命令」指运行 CCR 命令）

**技能**（Skill）：
编码平台可发现并按需加载的一组指令与辅助资源。技能可以提供斜杠调用入口，但不等于 CCR 的命令运行功能。
_Avoid_: 命令脚本（指技能时）

**插件**（Plugin）：
打包分发的一组扩展。
_Avoid_: 插件配置

## 活动

**操作记录**：
跨平台记录的配置操作及其结果，不是单个配置方案的内容版本历史。
_Avoid_: 版本历史（指操作记录时）

**Agent 会话**（Agent session）：
Claude Code、Codex 等编码工具留下的会话记录。这里的 agent 指编码工具本身，不是子代理。
_Avoid_: 会话（跨平台说的时候）

**记录费用**（Recorded cost）：
llmusage 按 API 价目估算的金额，不是账单，也不是实际支付的金额。
_Avoid_: 花费、账单、实付

**订阅设置**（Subscription settings）：
用户填写的订阅模式、套餐和月费，用来和记录费用对比。
_Avoid_: 订阅（只指这些设置时）

**订阅价值比**（Subscription value ratio）：
本月截至今日的记录费用除以用户明确保存的月费，不按天折算月费。它不是实际节省金额、账单折扣或已验证的投资回报；未设置订阅或月费不可用于计算时不显示比值。
_Avoid_: 回本、节省金额、投资回报（指订阅价值比时）

## 命令

**命令目录**（Command catalog）：
侧栏「命令」工作台里按可运行、仅预览、需专用页面分类展示的 CCR CLI 命令清单，只用于选择和编排 CCR 命令，不代表 Claude Code 等平台的斜杠命令。
_Avoid_: 斜杠命令、命令墙

**收藏命令**（Favorite commands）：
保存在本机桌面端、跨执行环境共享的常用 CCR 命令与参数组合。在编排区一键保存或取消，点击只载入编排区，不自动执行；不要在参数中保存凭据。
_Avoid_: 快捷运行（列表本身不执行）

**最近命令**（Recent commands）：
由命令运行器在任务终态自动写入的执行记录，只保存命令名、耗时、时间与成败，静止存储不保存位置参数。点击载入命令名与空参数。
_Avoid_: 完整命令历史、操作记录（操作记录指配置方案写入记录）

**运行账本**（Run ledger）：
命令工作台下方的任务状态与输出面板，集中显示状态、耗时、退出码、输出行数与按 `sys / out / err` 通道分组的虚拟化日志。清空账本只清除当前视图引用，不影响运行器保留记录。
_Avoid_: 终端、控制台（不是交互式 shell）
