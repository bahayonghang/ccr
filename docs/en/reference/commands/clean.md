# `ccr clean`

## Overview

Command: `ccr clean`

`clean` supports two cleanup targets:

- backup files under `~/.claude/backups`
- planning files generated by `planning-with-files`

## Usage

```bash
ccr clean [OPTIONS]
ccr clean planfiles [OPTIONS]
```

## Options

Run `ccr clean --help` for detailed options.

`ccr clean planfiles` only removes:

- `task_plan.md`
- `findings.md`
- `progress.md`

## Examples

```bash
# Clean old backups
ccr clean

# Preview planning file cleanup in the current directory
ccr clean planfiles --dry-run
```
