# `ccr clean`

## Overview

`ccr clean` is now the interactive cleanup entry point. Use explicit targets for scripts and automation:

- `ccr clean planfiles` removes planning files generated by `planning-with-files`.
- `ccr clean backups` removes old `.bak` files under `~/.claude/backups`.

Legacy backup flags on the bare command are still supported, so existing scripts such as `ccr clean --days 30 --dry-run` continue to run backup cleanup instead of opening the menu.

## Usage

```bash
ccr clean
ccr clean planfiles [OPTIONS]
ccr clean backups [OPTIONS]
```

## Interactive menu

The bare command shows a numbered menu of registered cleanup targets. Enter a target number to run it, press Enter to run the default target (`1.planfiles`), or enter `q` to cancel. `ccr -y clean` runs the default target and skips that target's confirmation prompt.

```text
Cleanup targets (enter a number to run, Enter = 1, q = cancel)
1.planfiles - remove task_plan.md / findings.md / progress.md
2.backups - remove backups older than 7 days
Select cleanup target [default 1]:
```

## Targets

### `planfiles`

`ccr clean planfiles` recursively scans the current directory and removes only these files:

- `task_plan.md`
- `findings.md`
- `progress.md`

It does not follow symlinked directories.

Options:

- `--dry-run`: preview matching files without deleting them
- `--force`: skip confirmation

### `backups`

`ccr clean backups` scans `~/.claude/backups` and removes `.bak` files older than the retention window.

Options:

- `--days <N>`: keep backups from the last N days (default: 7)
- `--dry-run`: preview cleanup without deleting files
- `--force`: skip confirmation

## Examples

```bash
# Open the interactive cleanup menu
ccr clean

# Run the default cleanup target without prompting
ccr -y clean

# Preview planning-file cleanup
ccr clean planfiles --dry-run

# Remove planning files immediately
ccr clean planfiles --force

# Preview old backup cleanup
ccr clean backups --dry-run

# Remove backups older than 30 days
ccr clean backups --days 30

# Legacy backup-cleanup form remains supported
ccr clean --days 30 --dry-run
```
