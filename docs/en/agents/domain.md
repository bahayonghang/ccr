# Domain Docs

This repo uses a multi-context domain-doc layout. Read the context that matches the area you are changing.

## Before Exploring

Check these files when they exist:

- `CONTEXT-MAP.md` at repo root
- the relevant local `CONTEXT.md`
- `docs/adr/`
- context-scoped ADRs near the affected area

If they do not exist, continue silently.
