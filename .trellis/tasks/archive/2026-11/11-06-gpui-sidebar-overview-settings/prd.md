# GPUI 侧边栏、总览与设置对齐 Tauri 工作台

## 目标

用户能一眼识别所在页面，读懂当前窗口的本机用量，快速找到设置并确认修改是否生效。按共享导航、总览、设置三个切片依次交付，各自独立验收。

## 验收条件

- [x] **共享导航。** 普通、悬停、按下、当前路由与键盘焦点清晰可辨。焦点移到另一项时仍可识别当前页，Enter 才切换。点击、Tab、F6、方向键、现有路由和可访问名称可用。导航列表独立滚动，底部设置、版本和状态栏互不遮挡。
- [x] **总览布局。** 状态、平台摘要、总量与趋势各有明确位置；汇总只出现一次。平台小图与堆叠图图例采用一致的身份色和文字。数字紧凑可读，精确值可查，日期刻度有序；总数含未进入逐日图的请求时显示差额。7D/30D/90D、刷新、监控和已有行动入口可用。
- [x] **总览数据。** 用已记录、真实零、缺库/未索引、读取中和失败验证显示。会话分别标明窗口、全历史或不可用。窗口切换或刷新失败时，不能将上一份报告标成新窗口的结果。无数据来源的 CLI 状态和逐平台会话数不填充。
- [x] **设置。** 标题与原生版本、主题和语言摘要在前，四个入口均可用键盘到达目标章节。修改主题、语言和退出策略时可见选中标记，界面与摘要即时更新。成功保存后重启可恢复；失败时显示真实状态并可重试。显示偏好文件、退出确认、环境管理、远程配置与通知操作仍可达。
- [x] **视觉验收。** 在同一常用桌面窗口、同一语言采集新版总览与设置首屏各一张，对照原图检查层级和可读性。检查深浅主题的选中/焦点与中英文标签；记录实际观察和未运行项。

## 范围

沿用原生 airy-glass 主题及系统字体。Tauri 是布局与交互参照。其他业务页、Tauri 产品代码、数据库与采集器、托盘、底色族、自定义字体、侧栏宽度持久化和全量窗口矩阵在本轮范围外。原 GPUI 迁移父任务已归档，本任务单独追踪。
