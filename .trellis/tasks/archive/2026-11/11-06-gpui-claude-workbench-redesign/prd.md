# 重构 GPUI Claude Code 工作台首页

## 目标

进入「Claude Code → 工作台」时，用户能在首屏辨认当前 Profile、本地凭据状态和本月费用，随后查看走势或直接进入认证、Profiles 和用量报告。Tauri 首页提供信息层级参照，原生字体、主题和导航遵循 `ccr-desktop/DESIGN.md`。

## 截图诊断与需求

| 编号 | 对照两张截图看到的问题 | 重构要求 |

## 验收标准

- [x] **R1** 常用桌面窗口、有数据时，首屏可同时看到标题、认证与 Profiles、配置摘要、三段金额及趋势区开头。长 Profile 和中英文标签可换行，主要操作仍可见。凭据只陈述本地观测结果。
- [x] **R2** 用隔离数据逐项对照三个时段及 30 天摘要。一个来源失败时，其他成功区域照常可读。读取中、无记录、不可用与返回的零各自可辨；刷新或换平台后，旧结果不会覆盖新页面。
- [x] **R3** 使用超过 7 条且包含缺日、零费用的记录，核对完整日期窗口与 USD 刻度；加入请求数高但费用低的日期，图上高度随费用变化。仅有一天时显示独立点，无记录时显示空态。从键盘可到达带日期和费用的明细。
- [x] **R4** 从首页分别进入认证、Profiles、订阅设置与限定 Claude 的完整报告，能够返回工作台；焦点可见。MCP、指令文件、Agents、Plugins、Commands、会话仍通过平台导航可达。
- [x] **视觉证据** 实施后留存同语言、同主题、同类数据的原生前后对照；记录窗口尺寸、首屏所见与点过的入口。按图 2 检查阅读顺序，自动化断言与真实窗口结果分别记录。

## 范围

限 GPUI Claude Code 首页。其他平台、全局侧栏、Claude 子页内部、Tauri 应用、数据库与计价规则不在本次范围内。Tauri 的 Token 详情、行为分析及项目/模型排名暂不移植，沿用已有详细报告入口。截图中的配置名、金额和颜色只作为观察依据，不写入生产数据。
