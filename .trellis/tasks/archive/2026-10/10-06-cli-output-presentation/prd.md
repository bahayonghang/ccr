# CLI 信息展示优化

## 目标与用户价值

统一 CCR CLI 的结果、详情、进度和操作建议。用户可以快速识别执行结果，读取必要信息，并复制与当前状态相关的命令。

## 背景与证据

用户提供 `ccr codex auth save teacher` 的成功输出，要求深入分析同类提示，并结合网络搜索创建完整 Trellis 优化任务。用户已同意创建并规划，已选择“简洁符号与分组”：终端中使用 `✓`，字段不带 `[INFO]`，操作建议按“下一步”分组，纯文本结果使用 `成功:`。

调查基线为 `dev` 的 `9fafc1116bc7d54004ab3b224b33c2f08cae6fcb`。初始工作树干净。`ccr-cli` 的 63 个文件中有 912 处 `ColorOutput` 引用，其中状态输出 784 处：success 138、info 422、warning 134、error 36、step 54。统计为源码语法匹配，包含文件内测试，不能视为运行覆盖率。

主要问题及精确证据见 [repository-assessment.md](research/repository-assessment.md)。网络来源与取舍见 [web-research.md](research/web-research.md)。完整调用清单见 [output-callsite-inventory.json](research/output-callsite-inventory.json)；消息语义复核入口见 [semantic-review-inventory.json](research/semantic-review-inventory.json)。

## 范围

覆盖 CCR CLI 共享状态标记，以及 Auth、Profile、Platform、Data、Sync、Lifecycle、Project、Update、Provider、Sessions、临时配置、UI 服务启动提示、Doctor 的同类文本。覆盖共享入口的 Codex 与 Sync 调用影响。

表格行列、交互问题、Clap 帮助目录、TUI、桌面 UI 和 VS Code 界面保持既有行为。纳入调查不代表每个文件都必须修改；每个引用必须有“修改、共享规则覆盖、保留及理由”的处置记录。

## 验收标准

| ID | 可观察结果 | 对应需求 |
| --- | --- | --- |
| AC1 | 交互终端的 save 成功首行为 `✓ 已保存账号 teacher`；邮箱位于缩进字段行，结果和字段无 `[OK]`、`[INFO]`。缺少邮箱时不显示空行或虚构邮箱。 | R1、R2、R7 |
| AC2 | 成功、警告、错误和进度在彩色及无色模式中可区分。统计、取消和正常空状态不被标为执行成功或错误。Doctor 的跳过与通过保持区分。 | R1、R3、R8 |
| AC3 | 结果内不重复显示共享标记和内嵌成功/错误 emoji；必要的风险文字仍可见。字段和消息正文不被共享函数整行着色。 | R3 |
| AC4 | save 成功提供查看账号建议；重复名称失败提供当前名称的覆盖命令及覆盖后果说明；未知状态和未登录只显示相应分支允许的操作。建议命令不包含 `$`、外层引号或混在同一行的说明。 | R4、R7 |
| AC5 | 默认重定向和 TERM=dumb 输出不含 ANSI、装饰性 Unicode 状态标记、动画或清屏；成功使用 `成功:`。NO_COLOR 终端保留 `✓` 等状态字符并去掉样式。既有显式强制颜色环境变量的例外按设计矩阵验收。 | R5 |
| AC6 | 已有 JSON 命令仍可由进程 stdout 解析为原有结构；不新增字段、状态标签或建议。各命令的退出码和输出流归属与基线一致。 | R6 |
| AC7 | Auth 合成夹具验证成功、缺字段、重复名称、未登录、不支持的存储、运行中警告、空列表、取消、失败与部分成功分支；无新增凭据明文或业务副作用。 | R7 |
| AC8 | 63 个 CLI 文件及共享入口外调用均有迁移处置记录；直接提示和 Doctor 输出也完成复核。保留项必须说明接口或范围原因。 | R8 |
| AC9 | Windows 实际终端在 40、80、120 列可读取结果和必要建议；长字段和命令不被人为截断。明暗终端中必要字段保持可读。 | R2、R5、R9 |
| AC10 | 子任务检查、机器输出回归及父任务 `just ci` 有当前源码证据。未执行的终端、平台或 hosted 检查明确标为 NOT_RUN 或 UNVERIFIED。 | R6、R9 |

## 不在范围内

- 修复已存在的 Auth 失败返回 Ok、修改退出码、批量迁移 stdout/stderr。
- 修改 tracing 文件日志、bridge、redaction、日志级别、日志权限或服务错误分类。
- 重做表格边框与列、帮助导航、交互确认、进度动画或全屏 TUI。
- 增加全局 quiet/verbose/color 开关、主题、配置项、输出框架或依赖升级。
- 修改账号校验、认证存储、数据格式、覆盖动作、真实账号或上游服务。
- commit、push、PR、release、任务归档及长期记忆写入。
