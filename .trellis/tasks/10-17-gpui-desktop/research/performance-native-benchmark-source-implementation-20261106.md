## Open comparison and performance boundaries

`Services::benchmark_clock()` exposes immutable manifest UTC as_of + timezone. Current workbench/home and other UI date labels/filters still have existing local/current-clock call sites; they were not silently replaced or caller filters overridden. Shared visible clock wiring remains open.

Validation reads marker+manifest (each max 1 MiB), walks directory metadata including all 10k session sources, and streams all bytes of four DBs (catalog absent only at S0). Tauri currently performs metadata-only validation. These are asymmetric real startup costs and cannot be subtracted from process-create→present. Diagnostic load durations observed in this headless test were approximately S0 22.8ms, S1 5.34s, S2 4.40s; they are not performance samples or a startup threshold result. A future harness must validate both endpoints equally before trials, or both clients need equivalent validation policies.

The existing native session consumer invokes provider_statuses→discover on every page, rescanning the full source tree. Full projection traversal therefore repeats 10k-source discovery about 50 times per populated scenario. This was exercised rather than bypassed. Separating provider inventory from page reads needs its own production behavior/change and verification; no cache was invented in this batch.

No present hook, JS paint, main return or on_next_frame surrogate was introduced. Real process/create→first-present/action-ready timing, S2 runtime emitter, common visible clock, full matched validation policy, UI/native observation, and other-OS source/storage checks remain open. S2 manifest stream workload is still not_emitted. All performance reports remain **not_run/not_comparable**. Whole-app/OS/native/performance acceptance is not claimed. Filesystem redirect rejection is implemented at load/selectors and domain writers; this batch does not claim an adversarial concurrent filesystem replacement proof.

Independent check and final integration gates are required before this batch is marked complete.
