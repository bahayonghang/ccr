# Grok Auth 多账号 TUI

## 目标、依赖与范围

让用户在既有 Grok Auth 页保存多个官方账号、查看与切换，并清楚看到选中项、本地会话匹配和操作结果。依赖 09-08-grok-auth-account-service 的服务契约与实现，集成 09-08-opencode-auth-residual-cleanup 的 theme 结果。切换已确定为停止当前 Grok 后执行，供新会话使用；保存可随时进行。已在服务 DTO/API 契约冻结后开始接入，最终集成等待服务实现。

## 需求

- R1：左账号列表、右选中详情/当前会话/结果；完整保留选择/分页，当前标记由服务匹配派生。
- R2：s 保存、Enter 切换、d 删除、o 登出、r 刷新；保存说明为复制到 CCR Grok 目录、当前账号继续使用，无结束/重启 Grok 前置；同名覆盖和破坏性动作明确确认，保存来源多 scope 时选择；不创建 token 编辑输入。
- R3：两种语言/主题和三类 ViewportMode 可读；空态、加载、未知/错误、过期、Busy、操作失败和成功后刷新失败分别呈现。
- R4：服务操作走后台阻塞任务，保证 mutation 一次在途，不因换页/退出而丢失结果或重放；主壳导航、语言、mouse、tick 和退出总结接入。
- R5：不展示 token/原始 JSON，不凭文件存在宣称认证有效，不画无数据配额；告知第三方 profile 保留和停止后切换、新会话使用的范围。

## 验收

- [ ] AC1（R1）：A/B 列表与当前/选中分离；上下/jk/PgUp/PgDn/鼠标选择，刷新/resize 后按别名保持，删项后邻近选择合理。
- [ ] AC2（R2）：保存/来源选择/同名覆盖/切换/删除/登出通过服务调用计数和临时目录回归；保存流程仅调用保存服务，文案包含 CCR 位置与当前账号继续使用，不检查进程退出、不出现结束/重启前置；取消零写，陈旧确认拒绝，重复触发不重复操作。
- [ ] AC3（R3）：140×40、100×30、80×24 两种语言与主题渲染，40×12 最小提示，长别名/邮箱/团队/CJK 不溢出；所有状态可见，无伪造指标。
- [ ] AC4（R4）：有界锁等待期间可处理 resize/语言；未提交弹窗换页取消，已提交 mutation 保留直到结果收集；不提前退出而遗失结果；disabled executor 或任务异常通道断开可恢复报错、不永久 Busy、不自动重放。
- [ ] AC5（R4）：主入口和 ccr grok auth 使用同一页；Tab/Shift+Tab/鼠标/语言/tick 正确委派，其他 Auth 不变；退出总结准确区分保存/切换/删除/登出。
- [ ] AC6（R5）：sentinel 不出现在帧/DTO/错误/日志；当前 scope 与认证路线不混同；切换确认说明先结束 Grok、供新会话使用，不承诺运行中立即切换。

## 非目标与状态

不改账号持久化/锁/core，不加 CLI/Tauri 账号接口、登录浏览器操作、用量/配额网络请求。不重构其他 Auth 的全局 overlay 系统。已进入实施。用户已授权实施并确定切换范围；本轮不运行测试/界面/真实账号操作，不触碰当前 Grok Build。AC 的动态证据保持未验证，测试源码按必要改动维护。
