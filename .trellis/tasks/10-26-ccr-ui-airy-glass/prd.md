# Tauri 前端轻盈玻璃视觉重构

## 目标与用户价值
按用户指定 /design-md 的 style:airy-glass，把 CCR Tauri 前端统一成轻盈、可读、适合高密度操作的桌面工作台。成功不是首页截图更柔和，而是所有现有页面与交互状态具有一致材质和清晰语义，不牺牲功能、可访问性与性能。

## 已确认背景
- 用户本轮明确要求深入分析并创建优化重构 Trellis 任务；授权范围为研究与规划。
- 当前 React/Tauri 前端的 ccr-ui/DESIGN.md 与 scoped AGENTS 定义行情终端，换风格需要同步规范、令牌与外观测试。
- 原始 airy-glass 提供薄荷至淡紫场景、纸面和绿紫语义，没有暗色及图表体系。原始快照见 research/catalog/DESIGN.md。
- 现有 light/dark/system、neutral/clay、字体偏好，以及1200×800默认/800×600最小窗口必须纳入兼容。代码锚点见两份 research 文档。
- 仓库并行开展 GPUI/共享服务工作；ccr-desktop 不在本次范围。启动时已有70项未提交路径。

## 需求与可观察验收
| ID | 需求 | 验收结果 |
|---|---|---|
| R1 | 统一设计语言 | 亮色有薄荷/淡紫静态场景和纸面，暗色有对应层级；规范、sidecar、CSS和主题测试一致 |
| R2 | 有限玻璃与可读性 | 同屏有效 backdrop-filter ≤1；列表、表格、表单、图表和弹窗实底；<960px/减少透明度/无blur支持时纸面不透明且blur为none |
| R3 | 全前端覆盖 | 每个实际页面有归属和验证记录，重定向/参数路由单列；首页、特殊背景页与独立托盘不遗漏；关键状态有证据 |
| R4 | 偏好兼容 | 主题/flavor/accent/字体存储、默认值与迁移行为不变；冷启动无错误主题闪屏，不强制切到亮色 |
| R5 | 行为保护 | 草稿/确认、键盘、虚拟列表、滚动恢复、tab/筛选、图表真实比例、作业生命周期和不可用状态不变 |
| R6 | 可访问性 | 保留现有严格文字阈值，验证实际合成背景；焦点清晰、状态有非颜色编码，最小窗口/缩放下核心动作可达 |
| R7 | 性能与证据 | 同环境同数据的前后性能记录；未测项明确NOT_RUN，Web不能冒充原生验收；CI门槛不降低 |
| R8 | 可控交付 | 四子任务可独立验证和回滚，不混入既有改动，不改变后端数据/权限合同 |

## 范围
包括应用外壳、主题/首屏、公共UI、配置/平台/资源/同步/认证页面，首页/用量/图表/会话/日志/作业页面，以及相关视觉规范和测试。仅进行必要的视觉布局适配，保留导航和信息架构。

不包括 GPUI、CLI/TUI、VS Code、站点重设计，Rust业务/IPC/数据库重构，系统透明窗口、新字体安装、新图表库、功能增删、发行、提交和推送。
