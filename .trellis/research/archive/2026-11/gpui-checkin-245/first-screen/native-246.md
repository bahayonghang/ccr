# #246 签到首屏 Windows 原生复核

中文界面的首次配置、账户检索、筛选返回与分币种余额摘要均已在宽浅和窄深窗口复核。非零滚动位置可恢复，键盘焦点仍回到侧栏，交由 #247 的账户详情容器处理。

## 构建和复采条件

- 实测工作树为 `fb5e1b0ae15c80993283d43923aeebf90c868e99`，Windows 11 build 26300，Rust 1.98.0 MSVC，默认顶层 features。图来自实际 GPUI debug 窗口。最终可执行文件由 `just desktop-test-ui` 内的 `cargo test --locked --test native_ui --test native_shell -- --skip export_bindings` 于 2026-11-25 05:47:44（美东）重链。复制文件后核验 SHA-256 为 `b6492555c13a1ddf5c548f7c1a34bd789c75b8c8c324af9d6e845e798c25810a`，大小为 113,523,712 字节。
- 逻辑客户区为 1280×800 浅色、960×640 深色。DPI 120，中文，默认字号 14/12。从真实侧栏「签到管理」进入，使用普通配对夹具 `checkin-pair-v1`；基线归档中的 `fixture_pair.py` 可生成同一无库或三账户数据。长列表追加 12 个启用的合成账户，未设置凭据或余额。
- 通过私有 Windows 桌面上的原生窗口消息点击、滚动、输入和按键。以 UIA 控件、DWM 边框内的 PrintWindow 图片及磁盘状态核对结果。归档图片只做 JPEG 编码，保留原始像素尺寸。账户工具、签到和余额刷新作业留待后续票验收。
