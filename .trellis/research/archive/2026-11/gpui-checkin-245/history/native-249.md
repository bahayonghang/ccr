# #249 签到记录与余额历史的 Windows 原生验收

从真实侧栏进入「签到管理」。用系统辅助功能树定位控件，向 GPUI 窗口发送点击、滚轮、输入和按键，并截取原生窗口。无库使用 1280×800 浅色，已配置使用 960×640 深色，均为 120 DPI 下的逻辑客户区。截图保留窗口边框。

2026-11-25，Windows 11 build 26300，中文，默认界面字号 14。候选源码 `9a922f812a153558ecf05193b6ccee744946bf02`，默认 features 的 Windows MSVC debug 程序 SHA-256 为 `c0b8496ec4e60d8c944a0973bc14fceabaf16b24a768a8065f4640d258c25183`。以普通配对 `--fixture-profiles` 和 `--fixture-registry` 启动。配置库含 3 个合成账户、47 条签到记录和 7 个原始余额快照；无库场景仅提供隔离路径。

| 实际操作 | 结果 |
| --- | --- |
| 无库打开「签到记录」，再回到账户 | 显示记录空态。从侧栏进入、打开记录及返回均未创建签到账户库、WAL/SHM、锁、密钥或迁移目录。[无库的记录页](empty-records.jpg) |
| 在记录页翻到第二页，再选失败、提供商、账户及消息关键字 `Daily review` | 47 条记录可翻页。组合筛选收窄到晨光测试账户的一条失败记录。按「修复凭据」进入的编辑器显示同一账户名；取消后，按一次 Enter 重新进入该账户的编辑器。[记录和翻页](records.jpg) · [组合筛选与修复入口](composed-filter.jpg) |
| 只输入失败记录的错误码 `cookie_expired`，再清除 | 搜索错误码没有匹配，清除后可再次翻页。记录浏览与编辑取消前后，库文件 SHA-256 相同。 |
| 打开账户详情，选 7 天，在日历中查看 2026-11-22 并展开逐日数值 | 11-01 首条样本前缺失。11-13 的无限值和 11-23 的空单位均不可用。11-21 有成功签到与实测 0 USD，11-22 延续 0 USD 并指明来源 11-21。11-24 实测 4.5 CNY，11-25 延续自 11-24。图表与逐日明细覆盖相同范围，保留真零及币种间的断点。[7 天图表与所选日期](balance-chart.jpg) · [精确值与来源日期](daily-values.jpg) |

四个场景共读取 71 次 UIA 控件树，检查可读名称、说明和值中的合成凭据标记，未发现标记。进程 stdout/stderr 合计 0 字节。这组操作覆盖本地 Windows GPUI 和现有数据库只读查询；独立读屏器及其他操作系统未实测。
